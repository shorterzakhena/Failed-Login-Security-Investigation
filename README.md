# Failed-Login-Security-Investigation

**Project Overview**

This lab introduces Windows security monitoring and authentication investigations.

The objective is to examine Windows Security logs, identify failed and successful login events, and understand how unusual login activity may indicate a security concern.

**Objectives**

- Understand Windows authentication events.

- Identify failed login attempts.

- Identify successful login events.

- Understand Windows Event Viewer.

- Recognize potentially suspicious login activity.

**Tools & Technologies**

- Windows 10 or Windows 11

- Windows Event Viewer

- Windows Security Logs

**Skills Demonstrated**

- Windows Event Viewer

- Security log analysis

- Authentication monitoring

- Failed login investigation

- Cybersecurity fundamentals

- Security documentation

  ## What I Learned

Explain how Windows records authentication activity and how security professionals use event logs during investigations.

**Results**

Document the login events you reviewed.

Explain whether you found failed logins, successful logins, both, or neither.

**Conclusion**

This lab introduced basic security monitoring and demonstrated how Windows authentication logs can help an analyst investigate potentially suspicious login activity.
